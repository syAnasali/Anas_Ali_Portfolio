## 🌟 Key Features

### 1. 🛰️ Spatial 2D Canvas Physics Engine (`HeroSection.jsx` & Canvas)
- Responsive particle constellation background running at 60 FPS.
- Smooth mouse-tracking physics with dynamic velocity damping.
- Interactive domain selector (`Full-Stack Web`, `AI & Data Science`, `Robotics & IoT`) that dynamically filters telemetry stats and highlights relevant engineering competencies.
- Trailing satellite cursor with precision coordinate tracking.

### 2. 🎯 System Architecture Inspection Drawers (`ProjectsSection.jsx`)
- Every project card features an **Inspect Architecture** trigger.
- Opens a dedicated architectural breakdown modal detailing:
  - **End-to-End Data Pipeline**: Flow diagrams tracing client inputs through middleware, background queues, AI inference models, and persistence layers.
  - **Engineering Challenges Solved**: In-depth explanations of algorithmic optimizations, rate limiting, and hardware constraints.
  - **Telemetry Benchmarks**: Production latency metrics and throughput numbers.
  - **Direct Source Links**: Verified links to GitHub repositories and live deployments.

### 3. 📅 Dual-Track Gantt Trajectory Engine (`ExperienceSection.jsx`)
- 1:1 dual-track Gantt timeline visualizing Education and Professional roles across 2023–2027.
- Central neon laser timeline with real-time particle emission scanner.
- Proportional time-strip layout mapping exact start and end dates onto month-scale coordinates.
- Mobile-optimized responsive timeline cards with touch-friendly layout.

### 4. 🔍 Spotlight Command Palette (`CommandPalette.jsx`)
- Triggered instantly via `Cmd + K` or `Ctrl + K`, or by clicking the navigation search icon.
- Fuzzy filtering across all website sections, project architectures, certifications, and developer social links.
- Quick action triggers to instantly copy email, dial phone, open WhatsApp, or launch the interactive CLI terminal.

### 5. 💻 Interactive CLI Terminal (`TerminalModal.jsx`)
- A fully functional developer terminal emulator featuring authentic scanlines and monospace typography.
- Supported commands:
  - `help` — List available shell commands
  - `whoami` — Display professional biography and background
  - `skills` — Output core language and framework proficiencies
  - `projects` — Query published software and hardware projects
  - `certs` — List official industry credentials and licenses
  - `contact` — Print active email, phone, and messaging links
  - `clear` — Clear the terminal screen buffer
  - `exit` — Close the terminal modal

### 6. 📡 Holographic Radar Contact Engine (`ContactSection.jsx`)
- Direct integration with Formspree for immediate serverless email routing.
- **Success State**: Cinematic holographic animation featuring dual concentric radar waves, particle sparks, a glowing green checkmark badge, and an encrypted receipt telemetry block.
- **Error State**: Resilient error banner preserving all user-entered form data with a single-click retry mechanism.
- Instant click-to-copy phone and email buttons with interactive toast notifications.
- Direct WhatsApp green glow messaging link (`+91 8740926817`).

### 7. 🌓 WCAG High-Contrast Dual Theme System (`ThemeToggle.jsx` & `index.css`)
- **Dark Space Mode** (`#000000` / `#030303`): Deep OLED blacks with neon cyan (`#38bdf8`), emerald green, and violet accents.
- **Light Blueprint Mode** (`#f1f5f9`): High-contrast slate canvas with deep navy headers (`#0f172a`), slate body text (`#334155`), and vivid electric blue anchors (`#0284c7`).
- Zero invisible text: Every card, border, badge, modal, terminal line, and tag maintains strict WCAG AA/AAA contrast ratios in both themes.

### 8. 🌐 Enterprise SEO & AI Agent Discovery
- **Rich Schema.org JSON-LD**: Comprehensive `@graph` encompassing `WebSite`, `ProfilePage`, and `Person` with credentials, education, affiliations, and skills.
- **Canonical URLs**: Canonical link tags preventing duplicate page indexing.
- **Social Media Cards**: Absolute OpenGraph and Twitter/X card tags with pre-rendered social preview images (`1200x630`).
- **Web Crawler Directives**: `robots.txt` configured with explicit rules for Googlebot, Bingbot, and modern AI engines (`GPTBot`, `ClaudeBot`, `PerplexityBot`).
- **Automated Sitemap**: XML sitemap (`sitemap.xml`) with updated priority weighting and section anchors.
- **LLM Context Engine (`llms.txt`)**: Machine-readable markdown synopsis following the `llms.txt` standard for AI search engines and LLM agents.

## 🛠️ Local Development & Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version `18.x` or higher recommended)
- `npm` (version `9.x` or higher) or `pnpm` / `yarn`

### 1. Clone the Repository
```bash
git clone https://github.com/syAnasali/Anas_Ali_Portfolio.git
cd Anas_Ali_Portfolio/Anas_Ali_Portfolio_Web
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
Generates a minified, chunk-split production bundle inside the `dist/` directory.

### 5. Preview Production Build Locally
```bash
npm run preview
```

## 🚀 Deployment

The portfolio is optimized for continuous deployment on **Netlify**:
1. Connect the GitHub repository to your Netlify dashboard.
2. Build command: `npm run build`
3. Publish directory: `dist`
4. The `public/_redirects` file automatically handles single-page application routing by redirecting all requests to `/index.html`:
   ```
   /*    /index.html   200
   ```
